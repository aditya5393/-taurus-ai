# Point 1 - ONE Killer Story (Award Demo Story)

**Don't demo 10 features. Demo ONE real story end-to-end.**

## The Story (2 minutes)

> "A 3rd-year student gives Taurus ONE goal: Research Agentic AI internships, draft Gmail to the top one, create a calendar reminder to follow up, and save a report."

**Taurus does:**
1. **Understand** - Router LLM understands: this is a multi-step goal
2. **Plan** - Planner breaks into 4 steps: Research → Draft → Calendar → Report
3. **Route** - Picks models: Research → Llama, Draft → Llama, Calendar → Llama, Report → Llama
4. **Act** - Searches, drafts Gmail (approval-gated), creates .ics calendar event, saves report file
5. **Verify** - Critic checks each step, fixes if needed
6. **Learn** - Saves lesson: "For internship emails, always include CGPA + semester"
7. **Result** - Shows Gmail draft + calendar event + report + trace

**Why judges remember this:** It's a real problem, real automation, real result - not "ask a question, get an answer."

## Demo Script (for video / live)
- 0:00-0:20 - Problem: "Students waste hours researching + emailing + tracking internships manually"
- 0:20-1:30 - Live: Give Taurus the ONE goal above, show Plan → Steps → Critic → Approval → Result
- 1:30-1:50 - Show Failure Recovery: Intentionally show buggy code fixed (Point 4)
- 1:50-2:00 - Result: "Saved 2 hours, 4 tasks done automatically" + Learning Curve graph
