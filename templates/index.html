Taurus Core / adaptive memory

Remember what matters. Improve from every correction.

Taurus separates temporary task context from durable, approved memory. It learns from verified outcomes and user corrections without treating every message as a permanent fact.

01

Working memory

Keeps the current goal, plan, tool results, and critic feedback together while a task is active. It is cleared when the run closes.

TASK ONLY

Taurus Core / system architecture

Think. Plan. Solve. Grow.

One clear loop: understand the goal, plan the work, route specialists, solve with tools, verify the result, and learn from approved memory and verified outcomes.

01 / INPUT

Understand

Read the goal, text, PDF or image evidence, constraints, and permissions.

02 / ORCHESTRATE

Plan

Break the goal into ordered, measurable steps.

03 / SELECT

Route

Choose the right general, code, or reasoning model using verified user outcomes.

04 / EXECUTE

Solve

Run specialists, retrieval, and tools against shared task state.

05 / CONTROL

Verify

Test outputs, repair failures, and gate external actions.

06 / MEMORY

Learn

Distill approved facts and verified corrections, then retrieve them only when relevant.

Semantic routing

The router judges required capability and context, so users never need to know or choose model names.

Model policy

Accuracy, tool support, latency, and fallback rules determine which approved specialist handles each subtask.

Human approval

The exact message, event, or file action is shown before any external system is changed.

Selective memory

Only important, approved facts and verified learning signals persist; each can be traced, updated, or forgotten.
